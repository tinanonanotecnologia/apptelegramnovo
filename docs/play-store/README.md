# Telegram Hub — imagens para a Play Store

Arquivos preparados a partir de capturas reais do aplicativo, em 1080×1920 (proporção 9:16), sem a barra do Chrome e sem a barra de navegação do aparelho.

## Ordem recomendada

1. `telegram-hub-phone-home-1080x1920.png` — tela inicial, busca e categorias.
2. `telegram-hub-phone-catalog-1080x1920.png` — filtros, categorias e listagem de canais/bots.
3. `telegram-hub-phone-detail-1080x1920.png` — detalhes e botão “Abrir no Telegram”.

`telegram-hub-phone-submit-1080x1920.png` mostra o formulário de envio de link e pode ser usado como quarta captura opcional.
